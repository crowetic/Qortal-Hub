# Cburnett chess piece sprite

The file `cburnett-chess-pieces.svg` contains chess pieces originally drawn
by Cburnett and adapted into a sprite by jurgenwesterhof.

- Source: https://commons.wikimedia.org/wiki/File:Chess_Pieces_Sprite.svg
- License: CC BY-SA 3.0
- License text: https://creativecommons.org/licenses/by-sa/3.0/

The SVG is stored locally so Qortal Land chess remains usable without loading
piece artwork from an external server at runtime.
